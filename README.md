# Prisma

**Color in motion.**

Prisma is an adaptive system for KDE Plasma, combining rich chromatic blur, wallpaper-driven colors and layered materials into cohesive experience.

## Design principles

- Dynamic wallpaper-derive colors
- Rich chromatic glass and refined solid surfaces
- Cohesive light and dark appearances
- Productive and distinctive desktop layout
- Comprehensive desktop and application styling
- Native-first performance and integration
- Minimal dependencies and implementation complexity

## Compatibility

Initial development targets KDE Plasma 6.8 on Wayland, using Fedora KDE Plasma Desktop 45

## Status

Currently in development.
